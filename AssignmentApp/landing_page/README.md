# 🚀 Nova AI - Flutter Web Landing Page

A modern and responsive AI-inspired landing page built using **Flutter Web**.

This project is created as an internship assignment inspired by the concept of the Gemini AI website, while maintaining a completely unique design, layout, and branding.


## ✨ Project Overview

Nova AI is a futuristic AI platform landing page that showcases:

* Modern AI branding
* Smooth animations
* Glassmorphism UI
* Responsive layouts
* Interactive hover effects
* Clean reusable Flutter widgets

The goal of this project is to demonstrate Flutter Web UI development skills, responsive design practices, and component-based architecture.

## ▶️ How to Run

### 1. Clone Repository

git clone <your-github-repository-url>

### 2. Open Project

cd Nova_AI

### 3. Install Dependencies

flutter pub get

### 4. Run Flutter Web

flutter run -d chrome


## 📦 Build For Web

To generate production build:


flutter build web

The output will be generated inside:


build/web/
